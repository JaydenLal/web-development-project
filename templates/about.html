About This Site

This website is a simple SQLite database viewer for esports tournament results. It shows player names, the game they played, their school, the tournament year, and the player's score. Use the menu at the top to change the sort order and use the search box on the table section to find a player's name.

How to use:

  • Go to the Home page to see the data sorted from highest to lowest.
  • Use the dropdown on the top-right to switch sorting order.
  • Type a name into the search box and press Search to filter results.
  • Clear the search box and press Search to see all records again.

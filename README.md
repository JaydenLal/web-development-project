# esports-dataset
The purpose for this dataset is to show how many users (anonymous players) played esports, all the games listed are purely fictional along with anonymous players to prevent copyright. This dataset shows the year they played, the specific game it is, which tournament they played in. The NZ city it was played in, and how much score they earned. 

The target audience are those interested in Esports and want to know about NZ’s current players. 

# How to run
download source code, open in VSCode, install Flask on the VSCode terminal, finally run it in VSCode with the terminal or "Run". Use the http://127.0.0.1:5000/ local webserver.
